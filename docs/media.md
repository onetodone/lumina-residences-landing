# Media assets

Every media slot is declared in `src/content/media.ts`. Most are filled with
real files already checked into `public/media/` — the hero poster, the hero
video, and all 9 gallery photos (`gallery01`–`gallery09`, referenced from
`src/content/gallery.ts` and reused by `src/content/unit-types.ts` for the
Unit Types photos). A slot with `src: null` instead renders an elegant
gradient + noise fallback rather than a broken image.

One slot is still a placeholder — to fill it, drop a file at the path below,
then set that slot's `src` in `src/content/media.ts` to `/media/<file-name>`.

The visual brief for every render: quiet luxury, architectural minimalism,
deep obsidian/graphite tones with soft champagne-gold accents, light and
water as recurring themes. No text or logos baked into the image.

| `facilities`          | `facilities.jpg` | 1200×1500        | Moody spa/wellness deck at dusk — dark stone tiles, soft ambient lighting, steam rising, no people. |

## Audio (smart-home widget)

The widget's Music row (`SmartHomePanel`'s `MusicPlayer`) is declared the
same way, in `src/content/music.ts` — a plain array instead of a keyed
object, since it's an ordered playlist rather than named slots. Filled
with 3 real clips already checked into `public/media/` (`audio-01.mp3`,
`audio-02.mp3`, `audio-03.mp3`). Add or remove array entries freely — the
player just maps over whatever's there, so the playlist length isn't
fixed at 3. A `src: null` entry renders present-but-inert (Prev/Next still
work, Play is disabled) rather than crashing or being omitted, the same
way a pending `media.ts` image slot falls back to the gradient + noise
background instead of a broken image.

Format: **MP3**, since it's the one format every major browser plays
natively (Safari doesn't support Ogg). Keep each clip short — these are
meant to be brief excerpts, not full tracks — and a modest bitrate
(128–192 kbps is plenty for background ambiance) to keep the page light.

Not covered by this manifest (generated in code, not stored as files):

- Open Graph image — generated by `src/app/opengraph-image.tsx` via `next/og`.
- Favicon — `src/app/icon.svg`.
